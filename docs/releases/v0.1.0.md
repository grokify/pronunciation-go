# Release Notes - v0.1.0

## Overview

The first release of **pronunciation-go**, Go packages for teaching speech engines how to say words.

Browser voices and many text-to-speech engines take plain text only, with no phonetic markup, so the way to fix a name they say wrong is to respell it: "Lamborgheeny" for "Lamborghini". Finding a respelling a voice reads as intended takes listening. The `respell` package turns what dictionaries publish, IPA and respellings, into several candidates to play and choose from.

## Highlights

- Respell IPA in the style of Wikipedia's pronunciation respelling key
- Bring IPA in other languages to the nearest English sounds
- Offer several candidate respellings per word for a voice to try
- Read text as Wikipedia writes it, such as `/ˌlæmbərˈɡiːni/ LAM-bər-GHEE-nee, Italian: [ferˈruttʃo lamborˈɡiːni]`

## Installation

```bash
go get github.com/grokify/pronunciation-go@v0.1.0
```

## Usage

```go
import "github.com/grokify/pronunciation-go/respell"

got, err := respell.Suggest("/ˌlæmbərˈɡiːni/ LAM-bər-GHEE-nee, Italian: [ferˈruttʃo lamborˈɡiːni]", "")
if err != nil {
	return err
}
for _, s := range got {
	fmt.Println(s.Source, s.Respelling, s.Candidates)
}
```

| Input | Respelling | Candidates |
|-------|------------|------------|
| `/ˌlæmbərˈɡiːni/` | LAM-bər-GHEE-nee | Lambergheenee, Lambergheeny, Lamber gheenee, … |
| Italian `[ˈɛntso]` | EN-tsoh | Entsoh, Entso, En tsoh, Ent soh |
| Italian `[ferˈruttʃo]` | feh-ROO-choh | Fehroochoh, Fehroocho, Feh roochoh, … |
| Spanish `[xeˈsus]` | kheh-SOOS | Khehsoos, Kheh soos, Khesoos |

## Added

### Reading IPA

`FromIPA(ipa, lang)` reads IPA into words of syllables with stress. Stress marks and syllable breaks start syllables; between vowels, the longest cluster that can start an English syllable goes to the next one. Affricates and diphthongs are joined and doubled consonants collapsed. `Word.Respelling` writes the result with hyphens, stressed syllables in capitals.

### Other languages

IPA in Italian, Spanish, French, German and other languages is brought to the nearest English sounds: pure vowels written long ("oh", not the "o" of "lot"), doubled consonants single, nasal vowels with an n. A rolled r or a doubled consonant is lost.

### Reading respellings

`FromRespelling` reads a hyphenated respelling such as `LAM-bər-GHEE-nee` back into syllables, a capitalized syllable taken as stressed.

### Candidates

`Candidates(word)` writes the same sounds up to `MaxCandidates` (8) ways, since voices read unfamiliar words by their own rules:

- as one word
- split where the stress falls
- syllable by syllable
- with simpler endings
- with a consonant cluster split

Which one a voice says best is found by listening.

### Wikipedia text

`Suggest(text, lang)` reads text as Wikipedia writes it and returns a `Suggestion` for each word, with its kind, language, source, respelling and candidates:

- IPA between slashes is English
- IPA in brackets is in the language named before it, such as `Italian: [...]` (see `Languages`), or `lang` when none is named
- hyphenated words outside them are respellings
